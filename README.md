# Projeto_MegaShop_Vendas_Excel
Projeto de análise de vendas desenvolvido em Excel, com tratamento de dados, criação de KPIs e análise de vendas.

# **Análise de Vendas - MegaShop**

Este é um projeto que desenvolvi para colocar em prática meus conhecimentos em **Excel e análise de dados**, trabalhando com uma base de vendas que possui algumas inconsistências.

A ideia foi passar por diferentes etapas, desde os dados brutos até o tratamento e organização das informações, criando também alguns indicadores para facilitar a análise dos resultados.

# Ferramentas utilizadas

* Microsoft Excel
* Tabelas dinâmicas
* Gráficos
* Fórmulas
* Tratamento de dados
* Indicadores (KPIs)

# Objetivos

* Analisar o desempenho das vendas
* Identificar e tratar inconsistências nos dados
* Analisar os produtos e categorias
* Observar o desempenho dos vendedores
* Analisar as vendas por cidade
* Criar indicadores que facilitassem a visualização e interpretação dos dados

# Principais análises

Durante o projeto, foram realizadas análises relacionadas a:

* Total de vendas
* Produtos
* Categorias
* Vendedores
* Cidades
* Identificação de inconsistências nos dados

A partir dessas informações, foram criados KPIs para facilitar a visualização dos resultados e entender melhor os dados disponíveis.

# Estrutura do projeto

O arquivo Excel foi organizado em diferentes etapas para acompanhar o processo de análise:

* **Dados_Vendas_Bruto:** dados originais da base
* **Dados_Vendas_Tratamento:** etapa de identificação e tratamento das inconsistências
* **Dados_Vendas_Limpo:** base após o tratamento dos dados
* **KPI_Cidades:** análise das vendas por cidade
* **KPI_Produtos:** análise dos produtos
* **KPI_Vendedores:** análise do desempenho dos vendedores
* **KPI_Categoria:** análise das vendas por categoria
